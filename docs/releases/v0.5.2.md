# Relay 0.5.2

Initial public pre-1.0 release.

## Included

- Native macOS tabs, recursive splits, draggable layouts, floating panes, pane zoom, and workspace restoration.
- Durable remote PTYs managed by the per-user `relayd` supervisor and pane workers. Closing a pane detaches it; explicit termination ends it.
- One multiplexed SSH transport per node with sequence-based output replay, acknowledged input, bounded queues, heartbeats, and automatic reconnect.
- Recovery of running pane workers after a supervisor restart, using validated manifests and private Unix sockets.
- Structured Codex and Claude activity, agent/subagent state, peer events, approvals, artifacts, and a cross-session activity inbox.
- An authenticated loopback terminal for the Codex app side panel that attaches to existing panes without opening a remote network port.
- Local rendering of remote files in the floating `rcode` editor, including syntax highlighting, save conflict checks, and diffs.
- Clickable URLs, source paths, and image paths; native image previews; and Finder file transfer into the active remote working directory.
- Prompt-aware selection, copy and paste, bounded undo/redo, Shift-Enter handling, and bracketed multiline paste for agent prompts.
- The bundled `xterm-relay` terminfo entry, installed idempotently for local and remote users with a safe `xterm-256color` fallback.
- Diagnostics for terminal traffic, queue pressure, connection health, latency, sessions, panes, supervisor state, and bounded logs.
- Signed and notarized macOS DMG/ZIP packages plus static Linux `relayd` binaries for amd64 and arm64.

## Current limits

- Relay currently owns one workspace window.
- Finder transfer accepts regular files up to 64 MiB; directories and resumable transfers are not implemented.
- The local screen cache is for display restoration, not persistent searchable scrollback.
- Interactive Codex and Claude TUIs still use structured hooks plus compatibility transcript observation until their native structured streams cover every event.

See the [README](https://github.com/genomewalker/relay-terminal#readme) for installation, architecture, keyboard shortcuts, helper management, and build instructions.
