# R workspace quick setup

The main toolbar's chart icon arranges the selected docked console and its linked
editor into the R workspace. Plugin activation uses the same arrangement. Other
panes are minimized, not stopped. Results stay on the right.

Activation checks for an existing companion handshake. For up to 30 seconds it
can bootstrap the companion at an empty radian prompt. A typed command, busy
console, continuation prompt or help pager is not an automatic setup target.
The target, connection and input revision are rechecked before submission.
Generic base-R `>` prompts are deliberately not treated as sufficient evidence.

This slice does not launch R, create a local/remote environment chooser, or install
R packages. An existing handshake remains a saved identity, not a liveness proof.
