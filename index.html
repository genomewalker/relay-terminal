Before you connect

A matching app and helper

Remote features use relayd on the host. Check the app and helper versions together. A new binary on disk does not mean an existing worker has upgraded.

Explicit access

Review the host and project before opening a plugin. Plugin reads are on demand. Switching tabs must not silently retarget a request.

Test with a disposable session

Development builds still need installed-app and remote acceptance. Do not make an unverified build your only way to reach important work.
