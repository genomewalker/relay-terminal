Terminal, files
and agents

Relay runs on your Mac. Remote shells run under relayd on the SSH host.

Sessions and panes

Group local and remote shells into tabs. Split panes or detach them into floating panels.

File editor

Edit files, view diffs and preview images without leaving Relay. Remote files stay on the host.

Codex and Claude

Run the CLIs in terminal panes. The activity panel shows captured agent and subagent updates; coverage depends on the integration.

Screenshots

Plugin views from the development build, using test data.

Plugins

Install plugins in Settings → Plugins → Manage plugins. Enable a plugin, then open it with the puzzle-piece button in a terminal pane.

HPC jobs v0.1.0 is available as an experimental release. The other five plugins are in development and do not have installable releases yet.

HPC jobsInspect and filter Slurm jobsExperimental prerelease

Job list

The published v0.1.0 lists owned jobs. Search and filter up to 500 loaded rows, with an explicit queue count.

Details, log tails, submission and cancellation remain development work outside that release.

ArtifactsBrowse and preview project resultsDevelopment

File previews

Browse folders and preview images, Markdown, text or CSV/TSV tables. Save a verified copy with the native dialog.

Files are limited to 8 MiB; previews are bounded. HTML is not executed and external images are not loaded.

Artifact features and limits
Agent activityRead captured subagent updatesDevelopment

Agent history

Search a snapshot of up to 100 agents. Expand identities, timestamped updates and recent pane activity.

This displays already-captured events. It does not send peer messages, answer approvals or guarantee complete provider history.

Agent activity features and limits
Git reviewInspect changed files and diffsDevelopment

File diffs

List and filter changed tracked files, then inspect staged and unstaged changes for the selected file.

Read-only, with bounded output. No commits, staging, untracked-file contents or agent handoff.

File downloads

Browse files, verify received bytes with SHA-256 and save atomically through the native macOS dialog.

Regular files up to 8 MiB. Large-file streaming, resume, directory transfers and Finder drag-out remain unfinished.

Detect project types and JavaScript package managers from manifests and lockfiles.

Suggestions only. The plugin does not install dependencies or run repository scripts.

Setup

Remote helper

Remote features use relayd on the host. Check the app and helper versions together. A new binary on disk does not mean an existing worker has upgraded.

Plugin permissions

Plugins use the host and directory of the selected pane. Review the permissions before enabling them.

Development builds

Keep another SSH client available when testing Relay with important sessions.
